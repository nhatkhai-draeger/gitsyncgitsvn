## GIT <==> SVN with LFS support
Script to synchronize change from SVN to GIT and vise versa.

Limitation: Due to SVN internal model difference with GIT. In order to have
this synchronization work, it required that master on git repository do not
contains any merge commits. Every time this occurred, it would required
advanced developer to manually correct and set the synchronized points
(master, and the svn/* branches).


## Link exist SVN repository to git

* Disallow everyone else to modify the remote master entire process

* Repair a .gitattributes file in folder XXX to specify which file
  extension or set of file name should be track as LFS.

* Repair a .gitignore and other .git files in folder XXX.

* Repair a EEE file define SVN user map to Git username and email.
  Each line in EEE have following format:
  ```
  SVN_USERNAME = GIT_USERNAME <USER_EMAIL>
  ```
  This file could be generated by run below command init_new_sync without
  `--authors EEE` part.

* Initiate the link
  ``` CD ROOT_OF_GIT_REPO
  THIS_SCRIPT_FOLDER/init_new_sync -v \
    --gitUrl DDD --gitDot XXX \
    --svnUser AAA --svnPwd BBB --svnUrl CCC --authors EEE \
    A_PROJECT_FOLDER_IN_SVN
  ```
  If failed, fix issue then rerun above command. Issue could be incorrect
  account, password, permission access SVN server, permission access GIT
  server


## Link exist git repository to SVN

* Disallow everyone else to modify the remote master entire process.

* Create a project folder on SVN
  ```
  svn mkdir CCC/A_PROJECT_FOLDER_IN_SVN --message "Add Project" \
    --username AAA --password BBB
  git clone DDD/GIT_REPO.git
  CD GIT_REPO
  git branch -f org_master origin/master
  ```

* Create a link to SVN.
  ```
  CD GIT_REPO
  THIS_SCRIPT_FOLDER/sync \
    --svnUser AAA --svnPwd BBB --svnUrl CCC --authors EEE \
    --init A_PROJECT_FOLDER_IN_SVN
  ```
  If failed, fix issue then rerun above command. Issue could be incorrect
  account, password, permission access SVN server, permission access GIT
  server

* Find the FIRST_DIFF_COMMIT on org_master
  ```
  CD GIT_REPO
  git log --format=%H org_master --reverse \
  | ( while read f; do
        FIRST_DIFF_COMMIT=$f
        git diff --summary --exit-code $f master || break
      done
      echo $FIRST_DIFF_COMMIT
    )
  ```

* If there is a FIRST_DIFF_COMMIT on org_master but not org_master, do:
  ```
  CD GIT_REPO
  git checkout -f master
  git cherry-pick FIRST_DIFF_COMMIT
  git push origin master
  THIS_SCRIPT_FOLDER/sync --svnUser AAA --svnPwd BBB
  ```
  It's OK of cherry-pick failed because it have nothing to commit

* Adjust master and svn branches:
  ```
  CD GIT_REPO
  git checkout -B master org_master
  git push origin master
  git branch -f svn/lfs/A_PROJECT_FOLDER_IN_SVN FIRST_DIFF_COMMIT
  ```

* Run finial sync to pull all git commit into svn
  ```
  CD GIT_REPO
  THIS_SCRIPT_FOLDER/sync --svnUser AAA --svnPwd BBB
  ```

## Link both existing git repository and svn repository

* Disallow everyone else to modify the remote master entire process

* Create a project folder on SVN
  ```
  git clone DDD/GIT_REPO.git
  CD GIT_REPO
  git branch -f org_master origin/master
  ```

* Create a link to SVN
  ```
  CD GIT_REPO
  THIS_SCRIPT_FOLDER/sync \
    --svnUser AAA --svnPwd BBB --svnUrl CCC --authors EEE \
    --init A_PROJECT_FOLDER_IN_SVN
  ```
  If failed, fix issue then rerun above command. Issue could be incorrect
  account, password, permission access SVN server, permission access GIT
  server

* C1. If there is a GIT_COMMIT on org_master branch that equivalence to
  svn/lfs/A_PROJECT_FOLDER_IN_SVN, do:
  ```
  CD GIT_REPO
  git checkout -B master org_master
  git push origin master
  git branch -f svn/lfs/A_PROJECT_FOLDER_IN_SVN GIT_COMMIT
  ```

* C2. If there is a SVN_COMMIT on svn/lfs/A_PROJECT_FOLDER_IN_SVN branch
  that equivalence to org_master, do:
  ```
  CD GIT_REPO
  git rebase --onto org_master SVN_COMMIT svn/lfs/A_PROJECT_FOLDER_IN_SVN
  git checkout -B master org_master
  git push origin master
  ```

* If C1, C2 are not possible, merge and resolve conflict as follow:
  ```
  CD GIT_REPO
  git checkout -B master org_master
  git push origin master
  git merge svn/lfs/A_PROJECT_FOLDER_IN_SVN
  ```

* Run finial sync to pull all git commit into svn
  ```
  CD GIT_REPO
  THIS_SCRIPT_FOLDER/sync --svnUser AAA --svnPwd BBB
  ```


## Keep thing sync
When the link and been established, it would need to run regularly this
keep both side in-sync
```
CD ROOT_OF_GIT_REPO/A_PROJECT_FOLDER_IN_SVN
THIS_SCRIPT_FOLDER/sync
```

## Scripts usages

### sync
The sync script is a main script doing the hard work. Run ``sync -h`` to
see all available options.

### init_new_sync
This script had been design to ease the work for establishing link with
multiple existing SVN repositories in one command.

### sync_for_scheduler
This script had been design to run sync on multiple linked repositories to
keep them in synchronized in one command.
